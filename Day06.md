## Important Cloud Security Tools

*These tools help cloud security engineers `protect`, `detect` and `respond` to threats.*

1. **IAM :** Manage users, roles and permissions. Enforce least privilege access.

2. **GuardDuty :** Intelligent threat detection and continuous monitoring of your accounts.

3. **Security Hub :** Central View of security alerts and compliance status across services.

4. **CloudTrail :** Track API activity and maintain audit logs for analysis and compliance.

5. **CloudWatch :** Monitor resources, logs, metrics and set alarms for real-time insights.

6. **AWS config :** Track resource changes and ensure compliance with config rules.

7. **Inspector :** Automated vulnerability assessment for EC2, containers and applications. 

8. **WAF & Shield :** Protect web applications from common attacks and DDos threats.

*These tools work together to strengthen your cloud security posture and reduce risks.*
